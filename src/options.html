Torrent2Synology

Sends magnet links, .torrent files, and any link with "torrent" in its URL to your Synology Download Station. Right-click a link and choose a download folder, or optionally capture left clicks.

Server settings
Full address including the port, as you use it in your browser for DSM.
HTTPS needs a trusted certificate. DSM's default certificate is self-signed, and the browser rejects it for the extension even if you have clicked through the warning in a tab. Use the http:// address, or install a trusted certificate on the NAS (for example Let's Encrypt in DSM's Security settings). Saving checks this.
Stored unencrypted in browser extension storage unless you enable encryption below. Use a dedicated DSM account with only Download Station permission.
Enter a current code and click Test connection once. DSM then remembers this browser as a trusted device, so no further codes are needed.
Download folders

Right-clicking a link offers each destination below. Folder is relative to the share root (e.g. video/TV Shows); leave blank for the Download Station default. Saving checks that each folder exists.

Send only magnet / .torrent links on left-click instead of opening them. All other links are not handled.

Blank = Download Station's default folder.
